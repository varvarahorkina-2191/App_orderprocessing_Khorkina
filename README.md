# Система управления заказами

Клиент-серверное desktop-приложение для автоматизации работы компании, занимающейся оптовой продажей оборудования для кафе и ресторанов.
Приложение позволяет работать с пользователями, заказчиками, товарами, способами доставки и документами. Доступные функции определяются ролью пользователя.

# Запуск

Перед запуском необходимо импортировать базу данных из файла:

```text
sql/order_processing.sql
```
База данных должна называться:

```text
order_processing
```
Настройки подключения находятся в файле:
```text
config/database.properties
```
Если в MySQL используются другой логин, пароль или порт, необходимо изменить значения в файле `config/database.properties`.
